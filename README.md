# AWS Security Labs

Hands-on AWS cloud security labs built in a personal sandbox account:
IAM policy evaluation, S3 exposure auto-remediation, incident response,
and L2 troubleshooting. Tools: AWS CLI, CloudTrail, EventBridge, Lambda (Python).

> Sandbox account only. Account IDs, ARNs, and identifiers are redacted.

## Labs

| # | Lab | Services | Status |
|---|-----|----------|--------|
| 1 | IAM policy evaluation: explicit deny, permission boundary, KMS denial | IAM, STS, S3, KMS | In progress |
| 2 | S3 public exposure detection + auto-remediation | S3, EventBridge, Lambda, CloudTrail | Planned |
| 3 | Leaked access key incident response | IAM, CloudTrail | Planned |
| 4 | EC2 connectivity troubleshooting | VPC, SG, NACL, Flow Logs | Planned |
